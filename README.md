# Movie Explorer

어두운 포스터 중심 UI로 영화를 검색하고 상세 정보를 살펴보는 React 학습 프로젝트입니다.

## 실행 방법

```bash
npm install
npm run dev
```

품질 검사는 `npm run lint`, 프로덕션 빌드는 `npm run build`로 실행합니다.

## Day 2 — Netflix-style UX Engineering

- Route-based Lazy Loading
- Suspense and Skeleton UI
- Image Lazy Loading
- Infinite Scroll with Intersection Observer
- Server State with TanStack Query
- Query Cache and Background Refetch
- Client State with Zustand
- Command Palette
- Page Transition

TanStack Query는 서버에서 가져오는 영화 목록 상태를 관리합니다. Zustand는 사용자가 앱 안에서 변경하는 내 목록 같은 클라이언트 상태를 관리합니다.
